Overall effects

After estimating effect sizes, we fit three multilevel, intercept-only meta-analytic models to estimate the overall effect of prenatal noise exposure on:

  • the mean outcome (lnRR),
  • the absolute variability (lnVR),
  • the relative variability (lnCVR).

Because studies can contribute multiple dependent outcomes, we use metafor::rma.mv() with the sampling variance-covariance matrices constructed in the preceding chapter.

Variance-covariance matrices (shared-group dependence)

We load the effect-size database and the matching sampling variance-covariance matrix (V) for each effect-size type. Chapter 3 uses metafor::vcalc() to represent dependence from shared prenatal-noise and control groups. It uses a working correlation of \(\rho = 0.5\) for multiple or repeated outcomes that share a group. Each matrix index records the effect-size order in the rows and columns of V.

load_metric_input <- function(effect, variance, matrix_file, index_file) {
  # Load the matrix and its row-order index from Chapter 3.
  V <- readRDS(file.path(derived_dir, matrix_file))
  index <- readr::read_csv(
    file.path(derived_dir, index_file),
    show_col_types = FALSE
  )

  # Arrange the effect-size database in the order recorded by the index.
  positions <- match(index$es_id, db$es_id)
  if (anyNA(positions)) {
    stop("The ", effect, " index contains an unknown es_id.")
  }
  metric_data <- db[positions, , drop = FALSE]

  # Confirm that the data, index, and matrix describe the same effect sizes.
  if (
    nrow(metric_data) != nrow(V) ||
      ncol(V) != nrow(V) ||
      !identical(as.character(metric_data$es_id), as.character(index$es_id))
  ) {
    stop("The ", effect, " data and VCV matrix are not aligned.")
  }

  # Confirm that every model row has a valid effect size and sampling variance.
  if (
    any(!is.finite(metric_data[[effect]])) ||
      any(!is.finite(metric_data[[variance]])) ||
      any(metric_data[[variance]] <= 0)
  ) {
    stop("The ", effect, " model data contain invalid values.")
  }

  # Confirm that the matrix diagonal contains the corresponding variances.
  if (
    max(abs(diag(V) - metric_data[[variance]])) >=
      sqrt(.Machine$double.eps)
  ) {
    stop("The diagonal of the ", effect, " matrix does not match ", variance, ".")
  }

  list(data = metric_data, V = V)
}

The lnRR model includes every effect size. The lnVR and lnCVR models exclude percentage outcomes because the mean and variance of a proportion are mathematically dependent. They do not provide independent information, so we do not calculate separate variability effect sizes for these outcomes.

Multilevel intercept-only meta-analytic models

We use metafor::rma.mv() to fit each model (Viechtbauer 2010). We provide one effect-size column as the response and its matching matrix as V. We use the same specification for all three models:

  • random intercepts for study (study_id),
  • random intercepts for effect size (es_id),
  • random intercepts for strain (strain),
  • REML estimation and test = "t".
fit_overall_model <- function(input, effect) {
  # Fit one intercept-only model with the matching data and VCV matrix.
  metafor::rma.mv(
    yi = input$data[[effect]],
    V = input$V,
    random = list(
      ~ 1 | study_id,
      ~ 1 | es_id,
      ~ 1 | strain
    ),
    test = "t",
    method = "REML",
    sparse = TRUE,
    data = input$data
  )
}

# Apply the same model specification to lnRR, lnVR, and lnCVR.
overall_models <- purrr::map2(
  metric_inputs,
  metric_specs$effect,
  fit_overall_model
)
names(overall_models) <- metric_specs$effect

overall_lnRR_model <- overall_models$lnRR
overall_lnVR_model <- overall_models$lnVR
