6  Publication bias

6.1 Approach

Following the protocol, publication bias is assessed with a funnel plot and an Egger-style regression test (Nakagawa et al. 2022). Because lnRR and its sampling variance are mathematically linked (the variance depends on the same means used in the numerator), regressing directly on the standard error can itself create a spurious asymmetry. Following the recommendation in Nakagawa et al. (Nakagawa et al. 2022), the Egger-type test below uses a sample-size-based precision proxy, \(\sqrt{1/n_{ex} + 1/n_c}\), as the moderator in the same multilevel model used for the overall effect, rather than the standard error itself.

Both diagnostics are exploratory: heterogeneity is expected to be substantial and many effect sizes are not independent, both of which make classic publication-bias tests less reliable than in a simple two-group design. They are reported for transparency and to flag whether a sensitivity analysis is warranted, not as a definitive test.

  vi = lnrr_var,
  cluster = dependency_cluster_id,
  obs = es_id,
  rho = 0.5,
  data = es
)

overall_model <- metafor::rma.mv(
  yi = lnrr_harm,
  V = VCV,
  random = list(~1 | study_id, ~1 | es_id, ~1 | strain),
  test = "t",
  method = "REML",
  sparse = TRUE,
  data = es
)

A funnel plot centred asymmetrically around the overall estimate, with a gap among small/imprecise studies, is the classic visual signature of publication bias - but with only 16 studies and substantial expected heterogeneity, some asymmetry is also consistent with genuine between-study variation. Read this plot alongside the regression test below, not on its own.

6.3 Egger-type regression

es_egger <- es %>%
  mutate(precision_proxy = sqrt((1 / ex_n) + (1 / c_n)))

VCV_egger <- metafor::vcalc(
  vi = lnrr_var,
  cluster = dependency_cluster_id,
  obs = es_id,
  rho = 0.5,
  data = es_egger
)

egger_model <- metafor::rma.mv(
  yi = lnrr_harm,
  V = VCV_egger,
  mods = ~ 1 + precision_proxy,
  random = list(~1 | study_id, ~1 | es_id, ~1 | strain),
  test = "t",
  method = "REML",
  sparse = TRUE,
  data = es_egger
)

summary(egger_model)
