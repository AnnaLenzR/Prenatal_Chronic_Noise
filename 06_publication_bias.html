Publication bias

We evaluate small-study effects and time-lag patterns for lnRR. We use the same sampling variance-covariance matrix and random-effects structure as the overall-effect model.

NoteVariable definitions
Variable Definition
sqrt_inv_e_n Square root of the inverse effective sample size, calculated as \(\sqrt{1/n_{ex} + 1/n_c}\).
publication_year Publication year extracted from study_id.
year_c Publication year centred on the mean publication year.

Analysis data and overall model

We load the effect-size database and reconstruct the complete VCV matrix with the same metafor::vcalc() specification used in Chapter 3. We then fit the intercept-only model that provides the centre line for the funnel plot.

# Load the lnRR effect sizes and sampling variances.
db <- readr::read_csv(
  file.path(derived_dir, "db_effect_sizes.csv"),
  show_col_types = FALSE
)

# Extract the four-digit publication year from study_id.
db <- db |>
  mutate(
    publication_year = as.integer(
      stringr::str_extract(study_id, "(19|20)[0-9]{2}")
    )
  )

if (anyNA(db$publication_year)) {
  stop("A publication year could not be extracted from study_id.")
}

# Construct the complete sampling VCV matrix.
VCV_lnRR <- metafor::vcalc(
  vi = lnRR_var,
  cluster = study_id,
  grp1 = ex_id,
  grp2 = con_id,
  w1 = ex_n,
  w2 = c_n,
  obs = es_id,
  rho = 0.5,
  data = db
)

# Fit the intercept-only multilevel model.
ma_all <- metafor::rma.mv(
  yi = lnRR,
  V = VCV_lnRR,
  random = list(
    ~ 1 | study_id,
    ~ 1 | es_id,
    ~ 1 | strain
  ),
  test = "t",
  method = "REML",
  sparse = TRUE,
  data = db
)

summary(ma_all)

Egger-type regression

We test small-study effects with an N-based precision term. This avoids using the sampling standard error as the predictor because lnRR and its sampling variance are mathematically related (Nakagawa et al. 2022).

# Calculate the N-based precision term for every effect size.
dt_egger_full <- db |>
  mutate(
    sqrt_inv_e_n = sqrt((1 / ex_n) + (1 / c_n))
  )

# Fit the Egger-type multilevel meta-regression.
egger_model_full <- metafor::rma.mv(
  yi = lnRR,
  V = VCV_lnRR,
  mods = ~ 1 + sqrt_inv_e_n,
  random = list(
    ~ 1 | study_id,
    ~ 1 | es_id,
    ~ 1 | strain
  ),
  test = "t",
  method = "REML",
  sparse = TRUE,
  data = dt_egger_full
)

summary(egger_model_full)

Time-lag pattern

We centre publication year and fit it together with the N-based precision term. The model retains the same VCV matrix and random-effects structure.

# Centre publication year on its mean.
db_decline <- dt_egger_full |>
  mutate(
    year_c = publication_year - mean(publication_year)
  )

# Fit publication year and the precision term in the same model.
year_lag_model <- metafor::rma.mv(
  yi = lnRR,
  V = VCV_lnRR,
  mods = ~ 1 + year_c + sqrt_inv_e_n,
  random = list(
    ~ 1 | study_id,
    ~ 1 | es_id,
    ~ 1 | strain
  ),
  test = "t",
  method = "REML",
  sparse = TRUE,
  data = db_decline
)

We display the fitted relationship between lnRR and publication year while retaining the precision term in the model.

# Draw the bubble plot on the centred-year scale.
time_lag_plot <- orchaRd::bubble_plot(
  year_lag_model,
  mod = "year_c",
  group = "study_id",
  xlab = "Year of publication",
  ylab = "Effect size (lnRR)"
)

# Replace centred values with publication years on the horizontal axis.
mean_year <- mean(db_decline$publication_year)
target_years <- pretty(range(db_decline$publication_year), n = 6)
target_years <- target_years[
  target_years >= min(db_decline$publication_year) &
    target_years <= max(db_decline$publication_year)
]

time_lag_plot <- time_lag_plot +
  ggplot2::scale_x_continuous(
    breaks = target_years - mean_year,
    labels = target_years,
    name = "Year of publication"
  )
