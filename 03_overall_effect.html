4  Overall effect

4.1 Model

This chapter fits one multilevel, intercept-only meta-analytic model to estimate the overall effect of maternal chronic noise exposure on offspring anxiety- and depression-like behaviour, using the harmonized lnRR (lnrr_harm) from Chapter 2. A positive overall effect means more anxiety-/depression-like behaviour under exposure; a negative effect means less.

Several effect sizes are not independent: some share a control group, and several studies contribute more than one outcome per study. Two things are used together to account for this, following standard practice for multilevel meta-analyses (Nakagawa et al. 2023):

  • a variance-covariance (VCV) matrix built with metafor::vcalc(), assuming a correlation of \(\rho = 0.5\) between sampling errors of effect sizes that share a control group (dependency_cluster_id, defined in Chapter 1) - 0.5 is a conventional working value used when the true within-cluster correlation is not estimable from the data, not an estimated parameter;
  • random intercepts for study_id (between-study heterogeneity), es_id (residual/within-study heterogeneity), and strain (heterogeneity attributable to rodent strain).

es <- readr::read_csv(file.path(derived_dir, "db_effect_sizes.csv"), show_col_types = FALSE) %>%
  mutate(across(where(is.character), as.factor)) %>%
  mutate(across(c(lnrr_harm, lnrr_var), as.numeric))
VCV <- metafor::vcalc(
  vi = lnrr_var,
  cluster = dependency_cluster_id,
  obs = es_id,
  rho = 0.5,
  data = es
)
overall_model <- metafor::rma.mv(
  yi = lnrr_harm,
  V = VCV,
  random = list(~1 | study_id, ~1 | es_id, ~1 | strain),
  test = "t",
  method = "REML",
  sparse = TRUE,
  data = es
)

4.3 Orchard plot

orchard_overall <- orchaRd::orchard_plot(
  overall_model,
  group = "study_id",
  xlab = "lnRR (harmonized)",
  flip = TRUE
) +
  ggplot2::scale_y_discrete(labels = c("1" = "Overall effect", "All" = "Overall effect"))

orchard_overall

Each small point is one effect size, sized by precision (inverse sampling variance); the large point and its interval are the model estimate and its 95% confidence and prediction intervals.
