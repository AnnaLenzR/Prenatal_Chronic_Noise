2  Data wrangling and central-tendency estimates

2.1 Purpose and data lineage

This chapter turns the reviewed extraction database into the analysis-ready table used from Chapter 2 onward.

The starting point is outputs/019ff719-4f39-7b31-8dee-189f2b3ff628/PCN_data_v10_clean.csv. That file is the endpoint of the cross-checking and correction work already completed outside this book (column names, category labels, the offspring_age_class variable defined in the protocol deviation addendum of 18 August 2026, and the gest_window re-label of gest_stage_ex_new). This chapter does not repeat that work, and it does not override any reported mean or SD: for 176 of 207 arms per outcome, c_sd/ex_sd is the value already extracted from the study (or from metaDigitise) and is carried through unchanged. Only two situations produce a new number in R, and both use methods already documented in c_se_derivation/ex_se_derivation:

  • 18 arms per outcome where only the median and Q1/Q3 were reported - the mean and SD are calculated from those quartiles using the Luo (2018) and Wan (2014) estimators, because no mean/SD was ever reported to begin with.
  • 13 arms per outcome where SD was not reported but SE was - SD is back-calculated as SE x sqrt(n), the standard conversion, so a value exists to carry into the effect-size formula.

The standard error (se_final) is calculated the same way for every arm: where an SE was already reported (65 of 207 arms), that reported value is used unchanged; where it was not (142 of 207 arms), it is calculated as SD/sqrt(n) using the mean/SD from the two bullets above. This is the same formula the extraction team already used to populate c_se_analysis/ex_se_analysis, so this chapter’s independent R recalculation is then cross-checked against those columns rather than replacing them. Concretely, this chapter:

  1. reads the documented derivation method for every effect size (c_se_derivation / ex_se_derivation) and shows how many effect sizes and studies used each method;
  2. calculates the mean and SD only for the rows where they are genuinely missing (median/Q1/Q3 only), passes through every other reported mean and SD unchanged, and calculates the SE only where it was not already reported - then cross-checks that recalculation against the extraction team’s own *_se_analysis columns;
  3. derives the handful of continuous fields that are still stored as free text (frequency_Hz);
  4. checks the result against a short set of validation gates and writes the analysis-ready file that Chapter 2 reads.

As in the original extraction, every derived value keeps a label recording how it was obtained, so a reported statistic and a calculated one are never visually indistinguishable.

luo_iqr_mean <- function(q1, median, q3, n) {
  weight <- 0.7 + 0.39 / n
  weight * ((q1 + q3) / 2) + (1 - weight) * median
}

wan_iqr_sd <- function(q1, q3, n) {
  denominator <- 2 * stats::qnorm((0.75 * n - 0.125) / (n + 0.25))
  (q3 - q1) / denominator
}

Only one situation needs a mean or SD calculated from another statistic: the 18 abramova_2023_biopsy rows tagged median_iqr_deferred_to_r above, where the study reported the median, Q1, and Q3 for each arm but not the mean or SD. These use the Luo et al. (Luo et al. 2018) mean estimator and the Wan et al. (Wan et al. 2014) SD estimator agreed for this project. Every other row already has a final mean and SD (by whichever route the table above shows), so this chapter passes those through unchanged.

The SE is handled the same way for every row, including the 18 above: if the study (or the extraction team, from digitised or emailed data) directly reported an SE, that value is used unchanged; otherwise SE = SD / sqrt(n) is calculated from the mean/SD obtained above. This is the same relationship the extraction team used to build *_se_analysis - the validation step at the end of this section confirms the two agree.

finish_arm_statistics <- function(data, arm) {
  n        <- data[[paste0(arm, "_n")]]
  mean_x   <- data[[paste0(arm, "_mean")]]
  sd_x     <- data[[paste0(arm, "_sd")]]
  se_x     <- data[[paste0(arm, "_se")]]
  median_x <- data[[paste0(arm, "_median")]]
  q1       <- data[[paste0(arm, "_q1")]]
  q3       <- data[[paste0(arm, "_q3")]]
  method   <- data$stat_derivation_method

  from_iqr <- method == "median_iqr_deferred_to_r"
  if (any(from_iqr & !(is.na(q1) | is.na(median_x) | is.na(q3)) & !(q1 <= median_x & median_x <= q3))) {
    stop("Invalid Q1 <= median <= Q3 ordering in the ", arm, " arm.")
  }

  # Mean: calculated only for the median/IQR rows; passed through otherwise.
  mean_final <- mean_x
  mean_final[from_iqr] <- luo_iqr_mean(q1[from_iqr], median_x[from_iqr], q3[from_iqr], n[from_iqr])
  mean_source <- ifelse(from_iqr, "luo_2018_median_iqr", method)

  # SD: calculated for the median/IQR rows (Wan et al.), and for the small
  # group of rows where a study reported an SE but no SD (SD = SE * sqrt(n),
  # 13 rows in `uygur_2010_aphyhun`, `uygur_2011_ankarauniv`, and
  # `abramova_2024_devneur`); passed through otherwise (including the
  # assumed-SD-equals-sqrt(mean) and raw-data-derived rows, which are already
  # final numbers, just obtained upstream of this chapter).
  sd_final <- sd_x
  sd_final[from_iqr] <- wan_iqr_sd(q1[from_iqr], q3[from_iqr], n[from_iqr])
  sd_from_se <- is.na(sd_final) & !is.na(se_x)
  sd_final[sd_from_se] <- se_x[sd_from_se] * sqrt(n[sd_from_se])
  sd_source <- case_when(
    from_iqr ~ "wan_2014_median_iqr",
    sd_from_se ~ paste0(method, "_sd_from_se_times_sqrt_n"),
    TRUE ~ method
  )

  # SE: use a directly reported/digitised/emailed SE unchanged; otherwise
  # calculate it from the mean/SD obtained above. This is computed for every
  # row, including the 18 median/IQR rows, which had no SE at all before.
  se_reported <- !is.na(se_x)
  se_final <- ifelse(se_reported, se_x, sd_final / sqrt(n))
  se_source <- ifelse(se_reported, paste0(method, "_se_reported"), paste0(method, "_se_computed_sd_over_sqrt_n"))

  data[[paste0(arm, "_mean_final")]] <- mean_final
  data[[paste0(arm, "_mean_source")]] <- mean_source
  data[[paste0(arm, "_sd_final")]] <- sd_final
  data[[paste0(arm, "_sd_source")]] <- sd_source
  data[[paste0(arm, "_se_final")]] <- se_final
  data[[paste0(arm, "_se_source")]] <- se_source
  data[[paste0(arm, "_mean_pre_zero_correction")]] <- mean_final
  data
}

2.4 Exact-zero continuity correction

The Luo estimator returns an exact zero mean whenever a study reports Q1 = median = Q3 = 0 (a “floor effect”, e.g. no head-out inspections recorded for any animal in that arm). log(0) is undefined, so the primary lnRR analysis replaces an exact-zero analysis mean with 0.9 times the smallest positive analysis mean observed in the same outcome stratum (assay_type, measurement_variable, data_type, data_units), matching the correction rule already agreed for this project. The uncorrected value is kept in *_mean_pre_zero_correction; the SD is not changed by this rule.

zero_correction_strata <- c("assay_type", "measurement_variable", "data_type", "data_units")

## Purpose and data lineage

This chapter turns the reviewed extraction database into the analysis-ready table used from Chapter 2 onward.

The starting point is `outputs/019ff719-4f39-7b31-8dee-189f2b3ff628/PCN_data_v10_clean.csv`. That file is the endpoint of the cross-checking and correction work already completed outside this book (column names, category labels, the `offspring_age_class` variable defined in the protocol deviation addendum of 18 August 2026, and the `gest_window` re-label of `gest_stage_ex_new`). This chapter does not repeat that work, and it does **not** override any reported mean or SD: for 176 of 207 arms per outcome, `c_sd`/`ex_sd` is the value already extracted from the study (or from metaDigitise) and is carried through unchanged. Only two situations produce a new number in R, and both use methods already documented in `c_se_derivation`/`ex_se_derivation`:

- **18 arms per outcome** where only the median and Q1/Q3 were reported - the mean and SD are calculated from those quartiles using the Luo (2018) and Wan (2014) estimators, because no mean/SD was ever reported to begin with.
- **13 arms per outcome** where SD was not reported but SE was - SD is back-calculated as SE x sqrt(n), the standard conversion, so a value exists to carry into the effect-size formula.

The standard error (`se_final`) is calculated the same way for every arm: where an SE was already reported (65 of 207 arms), that reported value is used unchanged; where it was not (142 of 207 arms), it is calculated as SD/sqrt(n) using the mean/SD from the two bullets above. This is the same formula the extraction team already used to populate `c_se_analysis`/`ex_se_analysis`, so this chapter's independent R recalculation is then cross-checked against those columns rather than replacing them. Concretely, this chapter:

1. reads the documented derivation method for every effect size (`c_se_derivation` / `ex_se_derivation`) and shows how many effect sizes and studies used each method;
2. calculates the mean and SD only for the rows where they are genuinely missing (median/Q1/Q3 only), passes through every other reported mean and SD unchanged, and calculates the SE only where it was not already reported - then cross-checks that recalculation against the extraction team's own `*_se_analysis` columns;
3. derives the handful of continuous fields that are still stored as free text (`frequency_Hz`);
4. checks the result against a short set of validation gates and writes the analysis-ready file that Chapter 2 reads.

As in the original extraction, every derived value keeps a label recording how it was obtained, so a reported statistic and a calculated one are never visually indistinguishable.

```{r}
#| label: central-tendency-functions

luo_iqr_mean <- function(q1, median, q3, n) {
  weight <- 0.7 + 0.39 / n
  weight * ((q1 + q3) / 2) + (1 - weight) * median
}

wan_iqr_sd <- function(q1, q3, n) {
  denominator <- 2 * stats::qnorm((0.75 * n - 0.125) / (n + 0.25))
  (q3 - q1) / denominator
}
```

```{r}
  method   <- data$stat_derivation_method

  from_iqr <- method == "median_iqr_deferred_to_r"
  if (any(from_iqr & !(is.na(q1) | is.na(median_x) | is.na(q3)) & !(q1 <= median_x & median_x <= q3))) {
    stop("Invalid Q1 <= median <= Q3 ordering in the ", arm, " arm.")
  }

  # Mean: calculated only for the median/IQR rows; passed through otherwise.
  mean_final <- mean_x
  mean_final[from_iqr] <- luo_iqr_mean(q1[from_iqr], median_x[from_iqr], q3[from_iqr], n[from_iqr])
  mean_source <- ifelse(from_iqr, "luo_2018_median_iqr", method)

  # SD: calculated for the median/IQR rows (Wan et al.), and for the small
  # group of rows where a study reported an SE but no SD (SD = SE * sqrt(n),
  # 13 rows in `uygur_2010_aphyhun`, `uygur_2011_ankarauniv`, and
  # `abramova_2024_devneur`); passed through otherwise (including the
  # assumed-SD-equals-sqrt(mean) and raw-data-derived rows, which are already
  # final numbers, just obtained upstream of this chapter).
  sd_final <- sd_x
  sd_final[from_iqr] <- wan_iqr_sd(q1[from_iqr], q3[from_iqr], n[from_iqr])
  sd_from_se <- is.na(sd_final) & !is.na(se_x)
  sd_final[sd_from_se] <- se_x[sd_from_se] * sqrt(n[sd_from_se])
  sd_source <- case_when(
    from_iqr ~ "wan_2014_median_iqr",
    sd_from_se ~ paste0(method, "_sd_from_se_times_sqrt_n"),
    TRUE ~ method
  )

  # SE: use a directly reported/digitised/emailed SE unchanged; otherwise
  # calculate it from the mean/SD obtained above. This is computed for every
  # row, including the 18 median/IQR rows, which had no SE at all before.
  se_reported <- !is.na(se_x)
  se_final <- ifelse(se_reported, se_x, sd_final / sqrt(n))
  se_source <- ifelse(se_reported, paste0(method, "_se_reported"), paste0(method, "_se_computed_sd_over_sqrt_n"))

  data[[paste0(arm, "_mean_final")]] <- mean_final
  data[[paste0(arm, "_mean_source")]] <- mean_source
  data[[paste0(arm, "_sd_final")]] <- sd_final
  data[[paste0(arm, "_sd_source")]] <- sd_source
  data[[paste0(arm, "_se_final")]] <- se_final
  data[[paste0(arm, "_se_source")]] <- se_source
  data[[paste0(arm, "_mean_pre_zero_correction")]] <- mean_final
  data
}

db <- finish_arm_statistics(db, "c")
db <- finish_arm_statistics(db, "ex")

bind_rows(
  db %>% count(arm = "control", mean_source = c_mean_source, sd_source = c_sd_source, se_source = c_se_source),
  db %>% count(arm = "experimental", mean_source = ex_mean_source, sd_source = ex_sd_source, se_source = ex_se_source)
) %>%
  arrange(arm, mean_source, sd_source, se_source) %>%
```

- **14 rows** (`abramova_2021_front`, same-sex-subgroup raw data) belong to the same raw-data recalculation already described above for that study.

## Exact-zero continuity correction

The Luo estimator returns an exact zero mean whenever a study reports `Q1 = median = Q3 = 0` (a "floor effect", e.g. no head-out inspections recorded for any animal in that arm). `log(0)` is undefined, so the primary lnRR analysis replaces an exact-zero analysis mean with 0.9 times the smallest positive analysis mean observed in the same outcome stratum (`assay_type`, `measurement_variable`, `data_type`, `data_units`), matching the correction rule already agreed for this project. The uncorrected value is kept in `*_mean_pre_zero_correction`; the SD is not changed by this rule.

```{r}
#| label: zero-correction

zero_correction_strata <- c("assay_type", "measurement_variable", "data_type", "data_units")

zero_correction_values <- db %>%
  group_by(across(all_of(zero_correction_strata))) %>%
  summarise(
    zero_correction_reference_mean = {
      candidates <- c(c_mean_pre_zero_correction, ex_mean_pre_zero_correction)
      positive <- candidates[is.finite(candidates) & candidates > 0]
      if (length(positive) == 0) NA_real_ else min(positive)
    },
    .groups = "drop"
  ) %>%
  mutate(zero_correction_primary_09 = 0.9 * zero_correction_reference_mean)

db <- db %>%
  # Drop these columns first (rather than relying on left_join to overwrite
  # them) so this chunk gives the same result whether it is run once or
  # re-run later in the same R session - re-running it without this line
  # would leave the old columns in place and add new ones with a ".y"
  # suffix instead, since the columns already exist in `db` after the first
  # run.
  select(-any_of(c("zero_correction_reference_mean", "zero_correction_primary_09"))) %>%
  left_join(zero_correction_values, by = zero_correction_strata) %>%
  mutate(
    c_mean_exact_zero = !is.na(c_mean_pre_zero_correction) & c_mean_pre_zero_correction == 0,
    ex_mean_exact_zero = !is.na(ex_mean_pre_zero_correction) & ex_mean_pre_zero_correction == 0,
    c_mean_final = ifelse(c_mean_exact_zero, zero_correction_primary_09, c_mean_final),
    ex_mean_final = ifelse(ex_mean_exact_zero, zero_correction_primary_09, ex_mean_final),
    c_mean_source = ifelse(c_mean_exact_zero, paste0(c_mean_source, "_zero_corrected"), c_mean_source),
    ex_mean_source = ifelse(ex_mean_exact_zero, paste0(ex_mean_source, "_zero_corrected"), ex_mean_source),
    c_sd_zero_review = c_mean_exact_zero & (is.na(c_sd_final) | c_sd_final == 0),
    ex_sd_zero_review = ex_mean_exact_zero & (is.na(ex_sd_final) | ex_sd_final == 0)
  )

db %>%
  filter(c_mean_exact_zero | ex_mean_exact_zero) %>%
  select(
    study_id, es_id, assay_type, measurement_variable,
    c_mean_pre_zero_correction, c_mean_final, c_sd_final,
    ex_mean_pre_zero_correction, ex_mean_final, ex_sd_final,
    zero_correction_reference_mean
  ) %>%
  knitr::kable(digits = 4, caption = "Rows receiving the exact-zero continuity correction.")
```

## Parse the remaining free-text fields

`frequency_Hz` is reported as a mix of single values and ranges (e.g. `"20,000-45,000"`). It is not collapsed to one number; the categorical acoustic band is what feeds the moderator models, and the midpoint is kept only for exploratory use. A range is `audible` at or below 20,000 Hz, `ultrasound` when entirely above 20,000 Hz, and `mixed_or_boundary` when it crosses that line, following the same rule already used in the extraction review.

`dam_age` and `loudness_dB` are already numeric in the v10 file, so they are used as is (aliasing `dam_age` to `dam_age_weeks` to match the moderator dictionary's naming). `dam_age` remains missing for 118/207 rows, as anticipated during extraction.

```{r}
#| label: parse-frequency

extract_numbers <- function(x) {
  if (is.na(x) || trimws(x) == "") return(numeric(0))
  normalized <- gsub(",", "", x, fixed = TRUE)
  hits <- regmatches(
    normalized,
    gregexpr("[0-9]+(?:\\.[0-9]+)?", normalized, perl = TRUE)
  )[[1]]
  if (length(hits) == 1 && hits[1] == "") return(numeric(0))
  as.numeric(hits)
}

frequency_values <- lapply(as.character(db$frequency_Hz), extract_numbers)

db$frequency_min_hz <- vapply(frequency_values, function(x) if (length(x) == 0) NA_real_ else x[1], numeric(1))
db$frequency_max_hz <- vapply(frequency_values, function(x) if (length(x) == 0) NA_real_ else x[length(x)], numeric(1))
db$frequency_mid_hz <- rowMeans(cbind(db$frequency_min_hz, db$frequency_max_hz), na.rm = FALSE)
db$frequency_format <- case_when(
  is.na(db$frequency_min_hz) ~ "not_reported",
  db$frequency_min_hz != db$frequency_max_hz ~ "range",
  TRUE ~ "point"
)
db$acoustic_band_from_frequency <- case_when(
  is.na(db$frequency_min_hz) | is.na(db$frequency_max_hz) ~ "not_reported",
  db$frequency_max_hz <= 20000 ~ "audible",
  db$frequency_min_hz > 20000 ~ "ultrasound",
  TRUE ~ "mixed_or_boundary"
)

db$dam_age_weeks <- db$dam_age

db %>%
  count(frequency_Hz, frequency_format, acoustic_band_from_frequency) %>%
```

## Dependence-structure identifiers

Several effect sizes share a control group: `shared_control == "yes"` for 103/207 rows, and in some studies (e.g. `barzegar_2014_hippo`) one control group (`con_id`) is reused against several different exposed cohorts (`ex_id`). That reuse is exactly the kind of dependence the protocol deviation addendum flags for the variance-covariance structure rather than the extraction sheet itself. Because `con_id` already identifies which rows share a control group's data - and, in this dataset, is finer-grained than grouping by `ex_id` alone would be - Chapters 3-5 build the variance-covariance matrix by clustering on `con_id`. This section just aliases it as `dependency_cluster_id` so later chapters read one clearly-named column instead of re-deriving the same idea, and checks that no cluster keys are missing.
