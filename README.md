# Prenatal Chronic Noise Exposure Meta-analysis

A multilevel meta-analysis of the effect of prenatal/gestational chronic noise exposure on anxiety- and depression-like behaviour in rodent offspring.

The active analysis and its reproducible record live in [`pcne_book/`](pcne_book/), a Quarto book. The single source extraction file used by that workflow is [`Data/PCN_data_ext_checking_v.3.csv`](Data/PCN_data_ext_checking_v.3.csv).

The active data flow is:

```text
Data/PCN_data_ext_checking_v.3.csv
  -> 01_data_wrangling.qmd
  -> Data/derived/PCN_analysis_ready.csv
  -> 02_effect_size_lnRR.qmd
  -> Data/derived/db_effect_sizes.csv
  -> VCV matrices, models, moderators, bias checks, and sensitivity analyses
```

## Protocol

The analysis follows a pre-specified protocol with documented deviations and additions:

- `protocol/PCNE_protocol_v.4_111425.docx` - the analysis protocol
- `protocol/` also holds the deviation/addition records referenced by the manuscript and analysis

## Repository structure

- `pcne_book/` - the active Quarto analysis sections, rendered to `pcne_book/_site/`
- `Data/PCN_data_ext_checking_v.3.csv` - the source extraction dataset read by the book
- `Data/derived/` - analysis-ready files, effect sizes, VCV matrices, and fitted-model objects generated by the book
- `Data/audits/` - current leave-one-out and sensitivity-analysis exports generated by the book
- `Data/CRIME-Q_Appraisal_Template.xlsx` - the appraisal workbook read by the CRIME-Q appraisal section
- `outputs/prisma/` - retained PRISMA supporting output
- `included_studies/` - full-text PDFs of the included studies
- `Metadigitise_figs/` - figures digitized with metaDigitise for studies reporting data only in plots
- `protocol/` - the protocol and its deviation addendum
- `Figures/` - manuscript-ready or manuscript-development figure exports

## How to reproduce the analysis

1. Open `ChronicNoise_Rodents.Rproj` in RStudio.
2. Open any section's setup chunk once to let `pacman` install the required R packages (each section lists its own).
3. Render the whole book: in RStudio's **Build** pane, click **Render Book**, or run `quarto render` from a terminal inside `pcne_book/`. The project disables frozen execution so every render reruns the analysis from the source extraction file.

The rendered site is written to `pcne_book/_site/` (not tracked in git - see below).

Every section resolves paths relative to the project root (`normalizePath("..")` with `execute-dir: project` in `_quarto.yml`), so the book renders correctly regardless of which machine or folder location it is run from, as long as the folder structure above stays intact.

The alluvial-plot section (`pcne_book/10_alluvial_plots.qmd`) is retained for manuscript figure development but is not yet included in the book render list.

## Publishing the rendered book to GitHub Pages

From a terminal inside `pcne_book/`:

```
quarto publish gh-pages
```

This renders the book and pushes the contents of `_site/` to a `gh-pages` branch on this repository, then prints the published URL (`https://annalenzr.github.io/Prenatal_Chronic_Noise/`). The first run will ask to confirm the destination and may open a browser window for GitHub authentication; afterwards, re-running the same command updates the published site with the latest render.
